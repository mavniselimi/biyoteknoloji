# WP-15 migration evidence

`report-regression-report.json` is the deterministic comparison between the
legacy report path and WP-15. It is generated by `pgx-report
legacy-regression` and verified by `pgx-report verify-regression`.

It carries no timestamp, no path and no host, so regenerating it reproduces
the same `content_hash`. It records `live_model_calls: 0` and
`network_used: false`: producing it calls nothing.

The legacy values it quotes are the evidence that something needed
correcting. None of them is described as validated, approved or clinically
meaningful, and none of them may be read as a statement about any medicine.

See `docs/migration/wp15-legacy-report-migration.md`.
