# H00 - risk summary

A baseline is load-bearing in a quiet way: everything after it is described relative to it, so an error here is inherited by every later artifact rather than being visible on its own.

## If this is decided wrongly

- **The wrong identity is now in history.** Correcting it means rewriting every object that descends from the baseline.
- **The wrong tree was frozen.** Every closure artifact afterwards describes a starting point nobody meant.
- **Publication without a decision.** A push would put quarantined legacy data and material acquired under undetermined terms wherever it was pushed to, and a push cannot be taken back.

## If this is not decided at all

- Less than the others. The baseline works as a reference whether or not anybody has confirmed it. The risk is that it is confirmed implicitly, by everything downstream depending on it, rather than deliberately.
