# H03 - risk summary

This boundary is the control that keeps a research demonstrator from reading as clinical advice.

## If this is decided wrongly

- **A warning that is present but not read as binding.** Wording that hedges achieves nothing; the reader takes the finding and leaves the caveat.
- **An incomplete prohibition list.** The scanner blocks exactly what it is told to block, and a missing category is a sentence that passes.
- **Approving the boundary as though it approved the platform.** It approves the limits, not the outputs, and an approval read the other way would license exactly the use the boundary exists to forbid.

## If this is not decided at all

- Reporting and security stay blocked, which is the correct behaviour, and no report may be issued.
