## What this project can and cannot say about your identity

It will record: `identity_verification: NONE_PERFORMED`.

This project performs no electronic identity verification and holds no
signature infrastructure. What it can honestly record is that a typed
attestation naming you was relayed to the repository. It will not describe
that as a verified signature, because it is not one — the same wording is used
for the one existing human attestation in this repository, and it will not be
upgraded for yours.

If you want something stronger — a signed PDF, an email from an institutional
address, a video call witnessed by a third party — say so and the project will
record what actually happened. It will not claim more than happened.
